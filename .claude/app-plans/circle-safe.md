## Context
Người dùng muốn 1 app kiểu Life360 (family location sharing) trong CareAi factory. CareAi hiện 100% local/no-account — tính năng lõi "xem vị trí thời gian thực người thân" cần server trung gian nên không thể local-only. Đã chốt qua `AskUserQuestion`: backend viết trong `dvc-api` (không Firebase), bỏ Find My/AirTag (Apple không cho 3rd-party), SOS chỉ làm phần technical thật (SMS on-device, không dispatch giả). Đây là app CareAi ĐẦU TIÊN cần tài khoản — phá vỡ nguyên tắc "không tài khoản" của factory nhưng bắt buộc vì bản chất tính năng.

Kế hoạch chi tiết đầy đủ (data model backend, API, milestone, rủi ro): xem `~/.claude/plans/happy-strolling-newt.md` (đã duyệt 2026-08-04) — bản tóm tắt dưới đây chỉ giữ phần cốt lõi tra cứu nhanh.

## Phân tích thị trường (tóm tắt)
Life360 là đối thủ trực tiếp (giá neo rõ ràng, hàng chục triệu người dùng trả phí) — sharp-test 4/4 cho tính năng lõi. Khoảng trống: Circle Safe KHÔNG cạnh tranh bằng dispatch/roadside/ID-theft thật (không khả thi với 1 dev solo) — định vị là "gia đình nhỏ, đơn giản, minh bạch" thay vì "dịch vụ an toàn toàn diện".

## Data model (mobile, TypeScript — backend xem `dvc-api/docs/srs/family-circle.md`)
```ts
interface Circle { id: string; name: string; role: 'owner' | 'member'; }
interface CircleMember { accountId: string; displayName: string; role: 'owner' | 'member'; lastLocation?: { lat: number; lng: number; recordedAt: string }; }
interface Place { id: string; circleId: string; name: string; lat: number; lng: number; radiusM: number; }
interface PlaceEvent { id: string; placeId: string; placeName: string; accountId: string; type: 'enter' | 'leave'; occurredAt: string; }
interface EmergencyContact { id: string; name: string; phone: string; }
```

## Kiến trúc kỹ thuật
- Redux slice: `src/redux/familyCircle/` (whitelist — circle/members/places/settings, nhỏ bounded), `src/redux/familyLocationHistory/` (KHÔNG whitelist — cache time-series), `src/redux/familyAlerts/` (KHÔNG whitelist — cache + cursor `since`).
- Storage: không sharding theo tháng cần thiết (dữ liệu chủ yếu ở server, mobile chỉ cache runtime).
- Polling: `GET /events?since=` mỗi 20-30s khi foreground (theo `AppState`); `watchPosition` gửi `POST /locations/ping` khi dịch chuyển ≥50m hoặc tối thiểu 60s.
- Backend đầy đủ: `dvc-api/docs/srs/family-circle.md`.

Free: 2 ngày location history, không giới hạn place/member ở MVP. Premium: placeholder tĩnh "Sắp ra mắt" (30 ngày history) — KHÔNG IAP thật, đúng Playbook mục 6.4.
